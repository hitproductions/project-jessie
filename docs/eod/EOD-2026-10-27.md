## A slash in a typed project (Howard's Slack test, ~18:02) - Slack Interactions v50 built, import owed

Kristine's Band Recording came out `BACKYARD LIVE // TEST SESSION / SONY MUSIC / AEG x BPV`: the project was typed
"Backyard Live // Test Session" and went into the title as typed (the build adds no slash; PROJECT / Client / initials are
joined with " / "). "//" happens to be harmless, but a single " / " in a project or client would make Change read the project
as the first half and the client as the rest. **Slack Interactions v50** turns any slash typed in a title part (project,
client, project code, meeting title, "Who is it for?") into " - " on Book a room and on Change - this title would now be
`BACKYARD LIVE - TEST SESSION / SONY MUSIC / AEG x BPV`. Existing titles are left alone. sim-slash-titles 10, all sims pass,
launch switches OK: QA. Import any time (it needs nothing else). PENDING 134.
