## 1. Recurring bookings — Stage 2 (server-side loop), live and verified

Recurring bookings are now **fully deterministic end to end**. The model passes only the
pattern; n8n computes the dates and creates the series. Builds on Stage 1 (18 Sep, `Expand
Series`).

- **NEW `Jessie — Book Series`** (`UAwFoifgkfL1xNP2`): on "yes" the agent calls it once with the
  pattern + booking details. It expands the dates, loops **Book Session** per date via an
  Execute-Sub-workflow node (`mode:each`), skips any date whose room is taken, and returns a
  booked/skipped summary. The model no longer drives the loop or the dates.
- **main v127–v128:** Book Series tool wired to the agent; Guard Probe's claim check accepts
  `book series`/`BOOKED_SERIES`; the prompt's "on yes" step calls Book Series once instead of
  looping Book Session. v128 fixes a missing `Booked by | ref:` on series events (see below).
- **`verify-ids`** now tracks Expand Series + Book Series (id + active state), after Expand
  Series silently defaulted inactive when created via the API (CLAUDE.md gotcha 0).

**Verification approach — instant feedback without the n8n UI.** Built a throwaway webhook
harness and `curl`ed it directly: first proved the `executeWorkflow mode:each` loop against a
read-only Room Availability (no bookings), then Book Series end to end (`BOOKED_SERIES`, the four
correct Tuesdays, four Book Session executions). Then a live-agent check via Slack: DM'd Jessie
"book M3 every Tuesday for 4 weeks" → correct dates → one confirmation → four independent events,
`claimProbe: booked: confirmed`.

**Bug the live check caught (v128).** Book-Series events carried no booker reference, so Cancel
Booking refused them ("carries no booker reference … cancelled by hand"). The `Booked by | ref:`
suffix is appended by the *tool node* in the main workflow (`{{Get Booker.Name}}` /
`{{Slack Trigger.user}}`), and the Book Series tool node was missing it. Fixed and verified: a
fresh M4 series carried the ref on every event and Jessie cancelled one cleanly.

Commits: `06d11e5` (Stage 2), `9283bd8` (ref fix). Draft code + design in
`workflows/drafts/recurring/` and session memory. Delivery healthy throughout.
