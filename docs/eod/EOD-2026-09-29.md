## Decisions today

- **Version labels:** `vN (vN-1 fixed)` only when a build repairs a problem the previous build introduced; otherwise
  2 – 4 words saying what it fixes, e.g. `v187 (bug 15 + two-cancel fix)`. Both the workflow title and the n8n
  version name carry it.
- **No room named:** Jessie suggests the highest-ranked free room for the session type and asks if it is OK. Naming
  a room in any message uses that room.
- **Initials in lowercase count** ("bp", "rg"); common words (na, tbd, me ...) never do.
- **The arranger question names the engineer already given** ("Daryl Reyes is down as the engineer ...").
