## What was found, and how

- **A rewrite the model never sees breaks the next turn.** Guard Probe asked for the client in place of "Book it?", but
  the model's memory holds its own reply, so "none" answered nothing. The answer is now told to the model on that turn.
  Two other rewrites keyed on the "Book it?" ending and silently stopped running behind it.
- **The Turn Log's Tools column hid Expand Series' inputs** ("Expand_Series()" read as an empty call); it lists them now.
- **The "which day" line was code, not the model** - v164's date question, which did not count a repeat pattern as a
  date.
- **A curly apostrophe broke bare answers.** Book Session's questions use "Who’s", the answer readers only matched
  "Who's"; a bare "me" or "bp" was missed since v73.
- **A renamed category silently disabled a guard** (v76): nothing failed, the check simply stopped matching.
- **Airtable:** Clients.Client Type is recoded to the four types (multiple select; read correctly since v73). Two
  clients' records hold two types - the in-house arrangers (Internal, Personal) and one producer (Advertising,
  Internal) - and are asked which. No Booking Defaults table was made; it is not needed (the type rules are in code).

## Decisions today

- **Short card everywhere:** title, Date / Dates, Time, Room. "Booked by" only on someone else's booking (cancel) or a
  booking for a colleague (series). No check code on any card.
- **The type question reads "Is this advertising work, or internal?"** - the options are the client's own Client Type
  tags (all four only when nothing decides it).
- **Four booking types**, worked out in code: the requester's words, then the client's Client Type, then producer ->
  Advertising, Meeting / Event -> Internal, Localization -> Entertainment, then the department; asked only when nothing
  decides it.
- **An engineer booking is never asked who the engineer is;** the question reads "Who's the engineer?".
- **On-behalf bookings:** the card says "For: <colleague>"; an arranger colleague with no other client is asked "on
  behalf of X, or X's own project?"; the requester is never the engineer by default there.
- **Session type is asked, not guessed** ("What kind of session is this?"), never taken from the room.
- **Default room: used if free and suitable** (a usual room for the session type); a named room always wins. Parked
  with Tel to fill in (PENDING 74).
