input ("full name and role, e.g. Tara Lim (Post Engineer)"), the description input, the prompt's description
format ("[Full Name] ([Role])") and the title's initials. Given "Drey", a made-up surname was the only way to
comply. On the eval twin with that wording: "Andre Cabuay" and "Andrei (Drei) Ramos" for "Drey", 2 of 2. With the
wording changed to "the name exactly as the requester gave it": the typed name, **27 of 27**.

**Then made deterministic,** like "booked for": `Booked For` reads the requester's own messages for the engineer,
the arranger, the project, the client and the time range, matches people against Bookers, and the booking tools
use those whenever the model's value holds a word nobody typed. Corrections ("change the engineer to Tara"), shifts
("an hour later") and Jessie's own offers once answered are respected. Book Session v55 fills in the full name,
initials and role from Bookers, and asks about what the requester typed, never an invented name.
