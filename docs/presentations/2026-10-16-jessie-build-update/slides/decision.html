The decision

Structure the input, keep the conversation

We put a limit on how bookings are entered, so the same request always gets the same result.

Forms take the details

Dates, times and rooms are picked from lists. No guessing.

Typing still works

Start with a message as before. What Jessie picks up is filled into the form for you.

Questions stay in chat

Ask what’s free, what you have, or which room suits a session.

So we decided to put some structure on the input. Anything that books goes through a form: dates, times and rooms are picked, not typed, so the same request always gets the same result. That makes Jessie predictable. But we kept the chatbot side. You can still start with a message the way you would before, and whatever Jessie picks up from it is filled into the form for you. And you can still ask questions in chat.
