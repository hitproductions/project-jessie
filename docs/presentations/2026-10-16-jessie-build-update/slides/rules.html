A benefit we didn't expect: the forms enforce our studio booking workflow better than the chatbot ever could. While building the chatbot we worked out very specific rules: which rooms suit which sessions, which studio pairs with which vocal booth, holding rooms for celebrity sessions, the details each kind of session needs. With the chatbot, those rules depended on the AI following them. Now the form simply only offers what fits.
