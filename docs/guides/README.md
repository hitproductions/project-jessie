# Guides for testers

Hand-outs for teammates trying Jessie in Slack (15 Oct 2026, live: main v273, Slack Interactions v22, Move Booking v32).
Both cover only what is live; update them when a build changes what a requester sees.

- `jessie-quick-start.html` - one page: booking, change / cancel, typing, questions, repeats, extra rooms, testing notes.
  Published: https://claude.ai/artifact/VdC8JHfscqvSLGEKF5mDui
- `jessie-test-guide.html` - the full step-by-step test guide: 14 scenarios with steps and what you should see.
  Published: https://claude.ai/artifact/16Lwz84jqMpa9HDeMbY7Wf

The published pages are private until shared from each page's Share menu. To update one, edit the file here and republish
it to the same link.
